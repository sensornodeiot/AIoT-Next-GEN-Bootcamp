# Module 0 — Introduction to IoT

**Goal:** Build the mental model needed before writing any firmware: what IoT is, the four-layer model, sensor/actuator/MCU component categories, and why this course uses PlatformIO.

## Topics

- What is IoT: sense → think → communicate
- The four-layer model: Physical, Connectivity, Processing, Application
- Component categories: microcontrollers, sensors, actuators
- Why PlatformIO instead of the Arduino IDE
- Course roadmap overview

## Lab

No hardware lab. Install VS Code + the PlatformIO extension and confirm it opens without errors.

## Deliverable

Can state the four IoT layers with an example of each, explain sensor vs actuator, and has PlatformIO installed and verified ahead of Module 1.
